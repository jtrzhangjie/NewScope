# 随附符号目录

`stepperctrl.json` 是用于初次启动和 Demo 演示的示例符号目录，提供变量名称、类型、大小及地址。

- Demo 模式根据变量元数据生成合成波形，不访问示例地址。
- 连接自己的目标板前，请通过界面的“导入”加载该板当前固件对应、带 DWARF 调试信息的 AXF/ELF；不要直接把示例地址用于其他硬件。
- 示例目录不是固件，不包含可烧录的 AXF/ELF 文件。
- 编译和发布会将该 JSON 复制到程序旁的 `symbols/` 目录。使用免安装版时请完整解压 ZIP 并保留该目录。
- 导入后的用户符号缓存位于 `%LOCALAPPDATA%\NewScope\symbols`，不属于仓库中的此目录。
