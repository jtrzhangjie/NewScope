# NewScope v1.0.4

面向嵌入式调试的 Windows x64 J-Link 变量示波器。

## 下载

- **NewScope-Setup-win-x64.exe**：普通用户推荐，双击安装。
- **NewScope-Portable-win-x64.zip**：完整解压，运行 `NewScope.exe`；保留旁边的 `symbols/`。
- **SHA256SUMS.txt**：校验附件完整性。
- **symbols.zip**：本次构建匹配的 PDB，供问题定位使用。

两种程序包均自包含 .NET 运行时。查看 Demo 不需要 J-Link：在程序目录执行 `.\NewScope.exe --demo`。连接硬件需要另外安装 SEGGER J-Link 软件，并导入与当前固件匹配、含 DWARF 调试信息的 AXF/ELF。

GitHub 自动附加的 **Source code** 压缩包用于获取源码；源码也可通过 `git clone https://github.com/jtrzhangjie/NewScope.git` 获取。

## 本版内容

- AXF/ELF 变量解析、多通道读取、最多四窗格波形、WATCH 统计、CSV 导出。
- 独立 worker 隔离 J-Link DLL，超时恢复、单实例和诊断 ZIP。
- 修复会话时间轴倒退、采集出错后无法恢复、订阅累积、同名符号丢失和导出文件保护问题。
- 修复窄尺寸绘图及缩放/拖动边界，优化范围、光标查询和曲线路径。
- 保持原有 UI 布局、配色、字体、控件和文案。

## 验证与限制

103 项自动测试通过。合成源满历史测试覆盖 32/128/256/512 通道；256 通道 × 2000 Hz 在真实窗口中采集和交互 300 秒，最终错误数为 0。详细结果见仓库中的压力测试报告。

高通道全览仍有绘图延迟；512 MiB 是缓存预算，非进程内存上限，快照会临时增加内存。合成速率不代表探针真实吞吐。IAR/Clang、复杂 C++ 类型、多探针、更长时间及真实掉电/拔线场景仍需验证。安装包当前未做代码签名。
